# HR Analytics Dashboard and Workforce Analysis

## Project Overview
This project focuses on analyzing HR workforce data using Microsoft Power BI. It aims to understand employee distribution, workforce trends, salary patterns, and attrition where the required data is available.

## Problem Statement
Organizations need clear insights into their workforce to support employee planning and HR decision-making. This project uses data analysis and visualization to present important workforce metrics in an interactive dashboard.

## Tools Used
- Microsoft Excel
- Microsoft Power BI
- GitHub

## Dataset Information
The project uses an HR analytics dataset containing employee-related information. The dataset source, number of records, columns, and relevant fields should be documented based on the actual file used.

## Data Cleaning
- Checked for missing values.
- Checked and handled duplicate records where appropriate.
- Reviewed data types and inconsistent values.
- Prepared the data for analysis and visualization.

## Analysis
The dashboard explores employee distribution by department, gender distribution, hiring trends, and other workforce metrics supported by the dataset.

## Dashboard
The interactive Power BI dashboard presents workforce information through KPI cards, charts, and visual summaries.

## Key Business Insights
Insights are derived from the actual dashboard and dataset. The analysis can help HR teams understand workforce composition, identify trends, and support data-driven planning.

## Project Files
- `Dataset/` — Original and cleaned data files, where available.

## Conclusion
This project demonstrates how HR data can be cleaned, analyzed, and visualized to support workforce reporting and informed business decisions.
